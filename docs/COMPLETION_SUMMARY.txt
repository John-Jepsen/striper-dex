   - NDBC Station 46042 data collection
   - Wind speed/direction → upwelling indices

2. VALIDATION & UNCERTAINTY (Trust Metrics)
   - Time-series cross-validation (5-fold)
   - Prediction intervals (90% CI)
   - Forecast skill metrics (MAE, RMSE)
   - Confidence indicators (High/Medium/Low)
   
   Impact: Users know when to trust forecasts

3. ENHANCED TIDAL INTEGRATION (Better Timing)
   - Tide phase scoring (flood/ebb bonus)
   - Prime fishing time detection (tide + dawn)
   - Tidal range classification
   - Current strength indicators
   
   Impact: "When to fish" recommendations

  NEW FEATURES CREATED
================================================================================

WEATHER FEATURES (7 new):
  • upwelling_index_24h         - 24h cumulative upwelling forcing
  • upwelling_index_72h         - 3-day persistent upwelling  
  • upwelling_hours_24h         - Hours of upwelling winds
  • air_sea_temp_diff           - Heat flux driver
  • wind_speed_mean_{6,12,24}h  - Multi-scale wind averaging
  • wave_energy_mean_24h        - Mixing indicator

TIDAL FEATURES (8 new):
  • tide_flood / tide_ebb       - Active feeding phases
  • tide_slack_high/low         - Low activity periods
  • is_spring_tide / is_neap_tide - Tidal range flags
  • tidal_current_strong        - Strong current indicator
  • prime_tide_time             - Optimal fishing window

TOTAL: 80+ engineered features (up from ~40)
